# Xử lý ngôn ngữ tự nhiên — UET.CS3142

Double-click `index.html` to open the course. No scripts, terminal commands, installation, Internet connection, or local server are needed.

The site contains plain HTML, CSS, and PDF files. Each session page embeds its PDFs and provides direct open/download links. The 15 sessions follow the đề cương, including the midterm in session 9. The Transformer page retains the three supplementary Stanford links.

All seven PowerPoint presentations have been converted to PDFs with readable filenames in this folder. The two original PDFs are also used directly. Original PPTX files are preserved in `.archive/original-pptx/`.

To publish, upload the HTML, CSS, PDFs, icons, and `2627-1/` folder together to any static host. The `.archive/` and `.preview/` folders are not needed. Keep relative paths intact.

If a browser blocks PDF embedding, use “Mở PDF trong tab riêng” or click a PDF link on the index. The PDF opens independently of the website.
